NX Porting Kit: open-source notices

NX Porting Kit is built with and downloads software from the following open-source projects. Each keeps its own
license; the ports it installs carry their own license files and credits.

  ReXGlue and sa2-nx       static recompilation and the Switch runtime
  reNut                    native renderer
  devkitPro and libnx      Nintendo Switch homebrew toolchain
  hacBrewPack              NSP packing
  nx-hbloader (ISC)        basis of the NSP loader
  Qt for Python (PySide6)  this application's interface (LGPL v3)
  Node.js                  runs the port's data tools (MIT)
  Pillow                   icon conversion (HPND)

No games and no Switch keys are included with this application.
